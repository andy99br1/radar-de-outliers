Chave da API do YouTube

Fica guardada só neste celular.

Como criar a chave grátis
  1. Abra console.cloud.google.com e entre com sua conta Google.
  2. Crie um projeto novo (qualquer nome).
  3. Em APIs e serviços → Biblioteca, ative a YouTube Data API v3.
  4. Em Credenciais, toque em Criar credenciais → Chave de API.
  5. Opcional: restrinja a chave a Apps Android, pacote com.radaroutliers.app, SHA-1 __SHA1__.
  6. Cole a chave aqui e toque em Salvar.
